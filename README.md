# Calculadora de IMC

## Descripcion

Aplicacion de consola desarrollada en Java que permite calcular y analizar el Indice de Masa Corporal (IMC).

Proyecto academico de desarrollo colaborativo utilizando Git y GitHub.

## Integrantes

- Andres: Integrador, Dev 1 y Dev 4.
- Darelt: Dev 2.
- Shaday: Dev 3.

## Distribucion de funcionalidades

| Funcionalidad | Responsable | Rama |
|---|---|---|
| Calcular IMC | Andres | feature/calcular-imc |
| Clasificar IMC | Darelt | feature/clasificar-imc |
| Peso minimo | Shaday | feature/peso-minimo |
| Peso maximo | Andres | feature/peso-maximo |

## Tecnologias

- Java
- Git
- GitHub
- Visual Studio Code

## Instrucciones de ejecucion

Compilar el proyecto:

```bash
javac -d out src/*.java
```

Ejecutar la aplicacion:

```bash
java -cp out Main
```
